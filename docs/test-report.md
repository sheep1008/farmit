## 1. 요약

- 필수 요구사항 49개 중 **통과 39 · 실패 5 · 서버 안에서 확인 필요 5**.
- 실패 5개의 원인은 아래 문제 3건이고, 모두 이 브랜치에서 고쳤다. **서버에는 아직 반영되지 않았다** (4절).
- 응답 시간(6절): 서버 주요 조회 API 21개 중 19개가 0.5초 이내, 초과 2개는 B2로 수정. 채팅(7절): 진행 상태 0.02초, 같은 질문 재요청 0.03~3.5초로 REQ-NFR-002 통과. Haiku 5.5 답변은 그대로 서비스할 수 있는 수준이고 개선점 7개를 적었다.
- 찾은 문제 3건:

| # | 문제 | 영향 | 상태 |
|---|---|---|---|
| B1 | 새로 clone 해서 README대로 띄우면 backend가 시작하지 못함 (`.env.example`의 빈 값 → `int('')`) | REQ-NFR-012 | 수정·확인 끝 |
| B2 | 시장 간 비교(날짜 없이)·"지금 팔면"이 서버에서 10~13초 | REQ-NFR-001, REQ-PRC-003 | 수정, 로컬 확인 끝. 서버 반영 필요 |
| B3 | 보도자료 수집(`press_collect`)이 어디에도 예약돼 있지 않아 서버 검색 결과가 0건 | REQ-COL-007, REQ-SRC-002 | cron·README 추가. 서버 반영 필요 |

## 3. 찾은 문제

### B1. 새 clone에서 backend가 시작하지 못함 (높음)

- 증상: `ValueError: invalid literal for int() with base 10: ''` (`config/settings.py`)
- 원인: `.env.example`의 `TRANSPORT_DEFAULT_COST_PER_KM=`(빈 값)이 빈 문자열로 들어온다. `os.environ.get(키, 기본값)`은 변수가 없을 때만 기본값을 쓴다. `.env.prod.example`의 `LLM_DAILY_LIMIT=`도 같다.
- 수정: 두 줄을 `int(os.environ.get(키) or 기본값)`으로 바꿈.
- 확인: 새 clone에서 health 200, 백엔드 499개·프론트 161개 통과.

### B2. 시장 간 비교·"지금 팔면"이 10초 넘게 걸림 (높음)

- 증상 (서버): `/api/prices/compare?item_id=10` 12.7~13.2초, `POST /api/recommendations/now` 10.3~12.5초. 홈의 "지금 팔면"과 가격 화면의 시장 비교가 열 때마다 이만큼 걸린다.
- 원인: "가장 최근 정산일"을 `MAX(trade_date)`로 구하는데, 맞는 인덱스가 `(item, market, trade_date)`뿐이라 등급을 걸러 내려고 품목의 모든 행(사과 40만 행)을 읽는다.
- 수정: ① `settle_price`에 인덱스 `(item_id, grade, trade_date)` 추가 (마이그레이션 `prices/0008`) ② `MAX()` 대신 날짜 역순 1건 조회.
- 확인 (로컬, 정산 547만 행):

| 호출 | 수정 전 | 수정 후 |
|---|---|---|
| 시장 간 비교 (사과) | 6.4~7.7초 | 0.02~0.3초 |
| 시장 간 비교 (없는 등급) | 약 5초 | 0.01초 |
| 지금 팔면 (사과 100kg) | 약 5초 | 0.04초 |

- 인덱스 없이 정렬만 바꾸는 방법도 재 봤다: 보통 0.04초지만 일치하는 행이 없으면 5.6초가 걸려 인덱스를 더했다. 인덱스 생성은 로컬에서 29초.
- 재발 방지: `deploy-check.sh`의 응답 시간 점검에 시장 간 비교를 더했다 (지금 서버에 돌리면 이 항목이 실패한다).

### B3. 보도자료가 서버에 한 건도 없음 (중간)

- 증상 (서버): 보도자료 검색이 어떤 검색어로도 0건.
- 원인: `manage.py press_collect`는 손으로 돌리는 명령인데 Airflow DAG·서버 cron·README 배포 절차 어디에도 없다.
- 수정: `infra/cron/farmit`에 매일 22:30 UTC(한국 07:30) 실행 줄 추가, README "처음 배포" 5번에 첫 적재(`--days 30`) 추가.
- 확인 (로컬): `press_collect --days 7` → 28건, 검색 "농업" 4건·"인플루" 5건.

### 그 밖에 본 것 (고치지 않음)

| 내용 | 판단 |

## 4. 서버에 반영할 것
